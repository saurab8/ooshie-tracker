# Adding your own photos

Each character looks for its photo at:

images/<set-slug>/<character-slug>.jpg

Set slugs:
- moana
- toy-story-5
- spider-man
- mandalorian
- disney
- pixar
- marvel
- star-wars

Character slug = the name, lowercase, spaces replaced with dashes.
Examples:
- images/moana/moana.jpg
- images/mandalorian/zeb.jpg
- images/pixar/mike.jpg
- images/pixar/lightning-mcqueen.jpg
- images/spider-man/spider-man.jpg
- images/star-wars/c-3po.jpg

If a photo is missing, the tile just shows the character's initials instead — nothing breaks.

Recommended: square-ish crop, at least 200x200px, .jpg to keep the site fast.
